# Mhamed Ben Gharbia — Portfolio

Editable static source files for the Hatchable portfolio project.

- `index.html` — page structure and portfolio content
- `styles.css` — design, responsive layout and animations
- `app.js` — mobile navigation, scroll effects and reveal animations

## Run locally
Extract the ZIP and open `index.html` in your browser, or use VS Code with Live Server. No Node.js installation or build step is required. Google Fonts are loaded online.
